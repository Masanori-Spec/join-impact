# Integration contract (v0.1)

Shared pure TypeScript engine `src/engine.ts`. Browser and CLI call async `auditJoin({leftText, rightText, options})`; it returns a JSON-safe deterministic report and throws `AuditError` with `code` and `message` on rejected inputs. Sync `analyzeJoin` takes the same request and returns the same report with input sha256 omitted; public consumers use auditJoin. UTF-8 text is validated (no lone surrogates); the original BOM is part of its digest. Export `parseCsv(text, delimiter=',')` for header selection, returning `{headers:string[], rows:{values:string[], record:number,line:number}[], bytes:number}`. Data record numbers start at 2, include header, and are not physical line numbers. Errors must render as text, never HTML.

Options: `leftKeys:string[]`, `rightKeys:string[]` (same length, 1–3); `measure:string` left column; `join:'left'|'inner'` default left; `blank:'never'|'match'` default never; `normalization:'exact'|'trim'|'nfc'|'trim-nfc'` default exact; `leftDelimiter` / `rightDelimiter` default comma, supported comma/tab/semicolon; `expect:{manyToOne?:boolean,maxUnmatchedRows?:number,maxExpansion?:string}` optional. Reject unknown option/expect fields. maxExpansion canonical nonnegative decimal string (e.g. '1.5', with no plus sign or redundant fractional zeros).

Report: `{schemaVersion:'1.0', inputs:{left:{sha256,bytes,rows,columns},right:{...}}, options:<resolved>, baseline:PlanReport, selected:PlanReport, comparison:{outputRowsDelta:string,joinedTotalDelta:string,newCollisionGroups:number}, expectations:{passed:boolean,checks:[{name,passed,actual,limit}]}, limits:{...}, notes:string[]}`. No timestamps or filenames. Baseline always exact with same join/blank; selected uses requested normalization.

PlanReport: `{normalization,counts:{leftRows:number,rightRows:number,outputRows:string,matchedLeftRows:number,unmatchedLeftRows:number,droppedLeftRows:number,multipliedLeftRows:number,extraOutputRows:string,blankLeftRows:number,blankRightRows:number,rightDuplicateGroups:number}, measure:{column,validRows,blankRows,invalidRows,original:string,retainedOnce:string,joined:string,dropped:string,replicated:string,netChange:string,absoluteReplicated:string,absoluteDropped:string}, witnesses:[{key:string[],keyTruncated:boolean,leftCount:number,rightCount:number,outputRows:string,unmatched:boolean,replicated:string,dropped:string,absoluteReplicated:string,absoluteDropped:string,leftRecords:[{record,line,measure:string,measureStatus:'valid'|'blank'|'invalid'}],rightRecords:[{record,line}],pairs:[{leftRecord:number,rightRecord:number|null}],samplesTruncated:boolean}],witnessGroupsTotal:number,witnessesTruncated:boolean,collisions:[{side:'left'|'right',key:string[],keyTruncated:boolean,rawKeyCount:number,rowCount:number,rawSamples:[{key:string[],keyTruncated:boolean,records:number[]}],samplesTruncated:boolean}],collisionGroupsTotal:number,collisionsTruncated:boolean,invalidMeasureSamples:[{record,line,value:string,truncated:boolean}],invalidMeasureSamplesTruncated:boolean}`

Witnesses include groups with dropped or multiplied rows, ranked by absolute affected contribution then lexical serialized key. Empty-unmatchable left groups are grouped by the selected normalized tuple with rightCount 0; collision raw samples distinguish original spellings. No Cartesian join is materialized. Collision groups report >1 distinct raw tuples within each side mapping to a cleaned tuple, including blank tuples. Comparing is descriptive; no plan is auto-recommended.

Decimal syntax: `[+-]?(0|[1-9][0-9]*)(\.[0-9]+)?`, at most 30 integer and 12 fractional digits. No whitespace, exponent, currency, thousands separators, NaN/Infinity. Blank/invalid amounts are excluded with explicit counts and samples; audit does not fail solely for them. Outputs use canonical exact decimal strings, no trailing zeros, zero is '0'. `NULL` and `null` are literal text key values. Blank means any component equals empty string *after the plan's normalization*. Normalization is trim Unicode JS whitespace then NFC (when both enabled), case-sensitive.

Hard default limits exported as LIMITS: UTF-8 4 MiB/file, 40,000 rows/file, 64 columns, 16,384 UTF-16 code units/cell, 128/header, 30 witness groups, 5 record samples/side, 8 pair samples/group, 20 collisions, 5 raw collision samples with 5 records each, 12 invalid samples, 160 displayed chars/value, 1 MiB JSON report. Resource errors reject rather than silently truncate audited data. Witnesses only may truncate and state this explicitly. Worker termination is cancellation.
