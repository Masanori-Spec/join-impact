CSVの結合で、合計が増える・消える理由を。集計値から原因のレコードまで、ひとつながりに確認できます。

実行時はブラウザー内だけで処理。CSVの送信、外部API、解析トラッキングはありません。

まずは、サンプルで架空のデータを読み込み、監査します

01 / INPUT

2つのCSVを用意する

L

結合前の金額・数量などを含むテーブル

R

キーの一致で左の各レコードと対応するテーブル

UTF-8 · 各4 MiB / 40,000行 / 64列まで。ヘッダー必須。ファイルの改行は保持し、テキストを編集するとブラウザーが改行をLFに変換します。

02 / JOIN POLICY

結合のルールを明示する

小数は正確に計算。空欄・無効値は除外して件数を表示します。通貨記号・指数・桁区切りは使えません。

大文字・小文字は区別。NULLは文字列。複合キーの一部が空欄なら空欄キーとして扱います。

↳

合計の変化には、理由があります

CSVと結合ルールを選ぶと、正確な合計・影響件数・原因レコードがここに表示されます。

03 / IMPACT REPORT

数字の変化を、レコードまで。

JSONにはキー・金額のサンプルと入力のSHA-256が含まれます。共有前に内容を確認してください。

何を、どう数える？

元の合計 → 残存1回 → 結合後

未一致で消えた金額と、重複で増えた金額を分離。正負が相殺しても、影響件数と絶対値で見逃しません。

レコード番号と物理行

レコード番号はヘッダーを1として数えます。引用符内に改行があるCSVでは物理行番号と異なります。

結合を実体化せずに監査

キーごとの件数から正確に計算。証拠のサンプルだけに表示上限があり、監査対象を黙って切り捨てません。
